# Gemini GameForge（Vercel）

一个基于 Gemini API 的生成式游戏工坊：生成“文字冒险 / 跑团”与“横版动作”原型，并支持**独立试玩页**与**离线可打开的 zip 导出**。

## 目标与要求

- 生成的游戏可以打包成 zip 下载，解压后**直接双击 `index.html` 本地运行**。
- 试玩必须在独立页面打开（如 `/game/1`），主页仅展示生成、预览与下载入口。
- 文字冒险跑团：**先生成总体剧情**（展示并允许用户修改）→ 用户确认 → **生成每一幕 JSON**（含文本、分支选项、CG 提示词等）→ **逐幕生成图片** → 组合为完整游戏。
- 横版游戏：**先输出完整素材清单（JSON）** → 生成所有图片素材（需要抠图的素材使用纯绿色背景）→ 本地算法抠图得到透明 PNG → 将素材与需求交给 AI 生成可玩游戏 → 打包输出。
- **每一步支持编辑与二次提交**，同时提供**一键生成到底**的自动流水线按钮。

## 主要能力

- **文字冒险 / 跑团生成**：分阶段生成，用户可编辑剧情大纲。
- **横版动作生成**：先出素材清单再出游戏代码，素材自动抠图。
- **离线可玩**：导出 zip，`index.html` + 本地资源即可运行。
- **独立试玩页**：生成后可打开 `/game/[id]` 试玩。
- **双模式交互**：分步编辑/重试 + 一键全流程生成。

## 交互模式

- **分步模式**：每一步都可编辑与二次提交，支持单步回退与重试。
- **一键模式**：自动串联 1-5 步，默认“自动确认上一阶段”，但允许中途暂停并回到任一步编辑。

## 生成流程（详细）

> 下列流程既可分步执行，也可一键自动执行（中途可暂停/回退）。

### 文字冒险 / 跑团

1) **剧情大纲**：AI 输出世界观、关键角色、主线冲突与结局方向。
2) **用户编辑 / 确认**：在 UI 中修改剧情大纲并确认。
3) **分幕 JSON**：生成每一幕的结构化内容：
   - `sceneId`
   - `title`
   - `text`（该幕文字内容）
   - `choices`（分支选项 + 指向场景）
   - `cgPrompt`（该幕 CG 提示词）
   - 其他必要字段（如结局标记、旁白、道具变更等）
4) **逐幕出图**：根据 `cgPrompt` 逐幕生成图片。
5) **组装与导出**：将 JSON + 图片打包为可离线运行的 `index.html`。

### 横版动作

1) **需求思考 + 素材清单**：AI 输出完整的**素材提示词 JSON**，覆盖：
   - 主角、敌人、道具、特效、UI、背景/场景块等
   - 标记是否需要透明背景（需要则要求纯绿色背景输出）
2) **素材生成**：批量生成所有素材图。
3) **抠图处理**：对绿幕素材进行本地算法抠图 → 透明 PNG。
4) **游戏生成**：把素材与关卡/机制需求交给 AI 生成完整 HTML5 游戏。
5) **组装与导出**：打包成离线可运行 zip。

## 导出包结构（建议）

```
GAME_ID.zip
├─ index.html
├─ assets/
│  ├─ cover.png
│  ├─ scene-001.png
│  ├─ player.png
│  └─ ...
└─ game.json (可选，仅用于调试/导出)
```

> 说明：`index.html` 不依赖外部 CDN；所有资源使用相对路径，确保 `file://` 打开可运行。  
> 运行时**不使用 fetch**读取 `game.json`，而是将游戏数据以内联 JSON（如 `<script type="application/json" id="game-data">`）嵌入 `index.html`，避免本地文件协议限制。

## 本地开发

```bash
npm install
npm run dev
```

浏览器打开：`http://localhost:3000`
如端口占用会自动切换（如 3001），以终端输出为准。

## 环境变量

`.env.local`：

```
GEMINI_API_KEY=你的密钥
GEMINI_TEXT_MODEL=gemini-3-flash-preview   # 可选：默认文本模型
GEMINI_IMAGE_MODEL=gemini-2.5-flash-image  # 可选：默认生图模型
```

## 试玩与下载（交互要求）

- 主页：输入创意、查看生成进度、编辑剧情大纲、触发生成。
- 生成完成：提供“试玩”与“下载 zip”，并支持全流程一键生成。
- 试玩：打开 `/game/[id]` 新页面运行游戏，不在主页内嵌。

## 实现注意

- 绿幕抠图建议使用服务器端图像处理（如 `sharp` 或 `canvas`）。
- `index.html` 需避免 `fetch` 本地文件失败问题：建议内联 JSON 数据，静态资源使用相对路径直接加载。
- 离线包不得依赖外部 CDN（JS/CSS/图片均需本地打包）。
- 每个生成步骤应可复用、可回退、可重试。
